# Сайт-поздравление

Это простой статический сайт для поздравления подруги с днём рождения.

## Что в папке

- `index.html` — главная страница
- `videoplayback.mp4` — видео для фонового воспроизведения
- `фото/` — папка с фотографиями, которые показаны на сайте

## Публикация на GitHub Pages

1. Загрузите эту папку в новый репозиторий на GitHub.
2. Убедитесь, что `index.html` лежит в корне репозитория.
3. В настройках репозитория (`Settings`) включите GitHub Pages.
4. Выберите ветку `main` и папку `root`.
5. Сохраните.

Если репозиторий будет называться `USERNAME/REPO`, сайт станет доступен примерно по адресу:

`https://USERNAME.github.io/REPO`

## Автоматическая публикация

В файле `.github/workflows/pages.yml` уже настроен GitHub Actions, который автоматически деплоит сайт при пуше в ветку `main`.
